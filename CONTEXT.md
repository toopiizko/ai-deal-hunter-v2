# Project Context

AI Deal Hunter helps Thai users judge whether a second-hand listing is worth buying. The current priority is Phase 1 only: a usable local prototype matching `ui-final-reference-phase1.PNG`.

## Decisions and assumptions

- Thai is the primary interface language.
- Data, AI summaries, risks, and price history are clearly mock/local in Phase 1.
- Local storage persists watchlists, comparisons, and alert switches.
- Product artwork uses lightweight placeholders so the offline shell has no external asset dependency.
- Authentication, Supabase, scraping, real AI, and real notifications remain out of scope.
